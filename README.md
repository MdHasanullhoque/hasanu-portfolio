# MD Hasanull Hoque — Portfolio

**ONE IDENTITY. TWO PROFESSIONAL WORLDS.**
Building Digital Experiences. Managing Real-World Operations.

React 18 + Vite 5 + Tailwind CSS 3 (JavaScript/JSX, React Router v6).
Runtime dependencies: `react`, `react-dom`, `react-router-dom` only.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Edit contact details

Open `src/lib/content.js` and set `EMAIL` and `LINKEDIN`.
While `EMAIL` is empty the contact form shows "The email address has not been added yet."

## Deploy

Works on Vercel as-is (`vercel.json` rewrites every path to `index.html`).
